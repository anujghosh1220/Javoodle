# Official Syllabus References — ICSE Class 10 Computer Applications

## Primary (authoritative) source

- **CISCE — Computer Applications syllabus, Examination Year 2028**
  `https://cisce.org/wp-content/uploads/2026/01/18.-Computer-Applications.pdf`
  (published January 2026; located via CISCE website index during this audit)

The official document prescribes **eight units** for the current syllabus:

1. Revision of Class IX Syllabus
2. Class as the Basis of All Computation
3. User-defined Methods
4. Constructors
5. Library Classes
6. Encapsulation
7. Arrays
8. String Handling
